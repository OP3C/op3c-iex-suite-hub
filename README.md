# OP3C Extension Suite: issue tracker

This repository is the public issue tracker for the **OP3C Extension Suite**, a set of commercial extensions for
[Open Integration Engine](https://github.com/OpenIntegrationEngine/engine). It holds no source code.

Use it to report a bug or to request a feature in one of the extensions:

- Backup
- DBCP Manager
- License Manager
- Lookup Tables
- Mask
- Prometheus
- Role-Based Access Control

## Before you open an issue

> [!CAUTION]
> **Everything posted here is public.** Never include patient data, message content, license keys, passwords, tokens,
> connection strings or host names of your organization. Removing an issue later does not undo what was already
> indexed or sent by email.

- Search the [existing issues](../../issues?q=is%3Aissue) first; your problem may already be reported.
- Replace real data with made-up values in every sample, log excerpt and screenshot.
- If you cannot describe the problem without sensitive information, write to
  [support@op3c.com](mailto:support@op3c.com) instead.

## Opening an issue

[Open a new issue](../../issues/new/choose) and pick the form that fits:

- **Bug report**: something does not work as documented.
- **Feature request**: something you would like an extension to do.

The versions the bug form asks for are in the Administrator: in the **OP3C** task pane, click **About**, then
**Copy**.

## Security vulnerabilities

Do not report a security vulnerability in a public issue. See the [security policy](SECURITY.md).

## Other requests

Questions about licensing, purchasing or your account go to [support@op3c.com](mailto:support@op3c.com) or
[op3c.com](https://op3c.com).

The OP3C Extension Suite is commercial software. Nothing in this repository grants a license to it.
