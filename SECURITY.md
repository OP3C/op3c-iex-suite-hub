# Security policy

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Report it privately, one of two ways:

- [Report a vulnerability](../../security/advisories/new) through GitHub's private reporting. Only OP3C sees the
  report.
- Write to [support@op3c.com](mailto:support@op3c.com) with "Security" in the subject.

Please include:

- the extension and its version, and the Open Integration Engine version;
- what an attacker could do, and what access they need to do it;
- the steps to reproduce it, with made-up data.

Never include patient data, license keys or credentials, even in a private report.

## What to expect

We acknowledge a report within 3 business days and tell you whether we could reproduce it. We keep you informed
until a fix is released, and we credit you in the release notes unless you prefer otherwise.

Please give us the time to release a fix before you disclose the vulnerability publicly.

## Supported versions

Security fixes are released for the latest version of each extension.
